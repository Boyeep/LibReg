# Jawaban Tugas LibraryReg

Jawaban lengkap dengan rancangan menu dan gambar halaman tersedia pada [blog-7-jawaban-libraryreg.html](../blog-7-jawaban-libraryreg.html).

Artikel penjelasan pembuatan proyek tersedia pada [blog-8-project-libraryreg.html](../blog-8-project-libraryreg.html).

## Ringkasan

1. **Deskripsi dan ruang lingkup:** aplikasi front end untuk pendaftaran anggota perpustakaan dan pengelolaan datanya. Menggunakan HTML, Bootstrap, CSS, JavaScript, dan localStorage, tanpa backend/database server.
2. **Halaman dan menu:** Beranda, Tentang Perpustakaan, Layanan, Daftar Anggota, Pendaftaran Anggota, dan Login Petugas. Pengelolaan anggota dibuka setelah login simulasi.
3. **Desain UI:** navbar biru, font Arial, hero teks dan foto, empat kartu layanan, statistik ilustratif, informasi fasilitas, dan footer. Form menjadi satu kolom pada ponsel.
4. **Implementasi:** enam halaman tersedia pada folder ini. Pendaftaran memvalidasi kolom wajib, format email, dan NIM/NIP unik. Petugas dapat mencari, melihat detail, mengedit, dan menghapus anggota dengan konfirmasi. Versi revisi dijalankan secara lokal sesuai permintaan; tidak ada deployment baru.

Cara menjalankan dan akun simulasi terdapat pada [README.md](README.md).
